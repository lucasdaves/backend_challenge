Backend Challenge - Places API
Uma API RESTful simples, mas robusta, construída com Node.js, Express e TypeORM para gerenciar uma "lista de desejos" de destinos de viagem (Places).

Este projeto foi desenvolvido como um desafio de backend e implementa uma arquitetura limpa (Controller, Service, Repository),
tratamento de erros centralizado, validação de entrada e documentação de API interativa com Swagger.

Link do Swagger: http://localhost:3000/api-docs/
